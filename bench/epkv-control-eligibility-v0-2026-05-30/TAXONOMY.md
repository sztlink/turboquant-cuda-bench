# N=500 autopsy taxonomy

This taxonomy is a Day 1 machine-only autopsy for the `EPKV Control Eligibility v0` sprint.

It asks why the N=500 gated answer rerank did not beat direct entity-hop path prompting, and whether any failure slice still looks control-eligible.

## Important boundary

This is not a deployable detector. It is an autopsy.

Gold answer and machine metrics are used to label failures after the fact. Day 2 must remove gold-derived features from any operational eligibility detector.

## Primary labels

| label | meaning | control readout |
|---|---|---|
| `solved_by_path_prompt` | direct entity-hop path prompt had exact match | not a failure; control must not harm these |
| `answer_extraction_or_scoring_artifact` | path prompt missed EM but had `contains=1` or high F1 | potentially fixable by extraction/normalization, not necessarily EPKV |
| `model_refusal_or_unknown` | path output was blank, UNKNOWN, not mentioned, not enough info, etc. | potentially control-relevant if evidence is present |
| `retrieval_answer_absent` | gold answer string was absent from retrieved docs | not a control target by default |
| `partial_path_schema_or_support_miss` | answer present but support/path recall incomplete | mostly path/schema/retrieval construction, not sampler control |
| `path_schema_miss_answer_present_elsewhere` | support title recall was zero but answer string appeared somewhere | path construction miss; possible hard borderline |
| `evidence_present_not_closed` | answer string and full support were present, but path prompt failed | strongest natural slice for Day 2 eligibility work |

## Precedence

The classifier assigns one primary label in this order:

1. `solved_by_path_prompt`
2. `answer_extraction_or_scoring_artifact`
3. `model_refusal_or_unknown`
4. `retrieval_answer_absent`
5. `evidence_present_not_closed`
6. `partial_path_schema_or_support_miss`
7. `path_schema_miss_answer_present_elsewhere`
8. `uncategorized`

Rows also carry flags such as:

```txt
answer_string_present
answer_string_absent
no_support_title_recall
partial_support_title_recall
full_support_title_recall
full_support_recall
incomplete_full_support
candidate_has_gold
path_output_in_candidates
path_refusal_like
strong_solved_path_failed
path_solved_strong_failed
```

## Caveats

- `answer_string_present_in_docs` is a gold-derived audit feature. It is not operational.
- `candidate_has_gold` is a gold-derived audit feature. It is not operational.
- High F1 / contains cases may be scoring artifacts, answer-format issues, aliases, or genuine partial answers.
- `evidence_present_not_closed` is a machine proxy, not proof of internal evidence use.
- The taxonomy explains where control might be possible; it does not show a control delta.
