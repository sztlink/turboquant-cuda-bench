# Privacy audit

This package contains synthetic action-router fixtures and aggregate/computed metrics.

Included:

- synthetic aliases, targets, case families, and metrics;
- generated summary tables;
- historical runner script for reproducibility context.

Excluded:

- Discord-derived raw data;
- private project/customer data;
- credentials/tokens;
- raw model output traces in the public sanitized summary.

Note: target strings use invented `AYA-*`, path, snake-case, compact, and numeric forms. They are synthetic payload identifiers, not production identifiers.
